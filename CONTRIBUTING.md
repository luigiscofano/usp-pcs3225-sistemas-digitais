# Contribuir

Comece pelo README e por docs/PROCEDENCIA.md. Use uma branch por alteração real e explique entrada, comportamento final e evidência de execução no PR. Atualize exemplos quando mudar o contrato. Preserve créditos e diferencie código de estudo e acervo. Não use datas retroativas ou revisões fictícias. A suíte de testes precisa passar antes da integração.
